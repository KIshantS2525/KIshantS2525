## 🚀 Self Projects

### 🎨 DiagramStudio
> *Turn a plain English sentence into a live, editable diagram — instantly*

Built with **Mohini Sharma**. A browser-based app where you describe a system in plain English and get a fully interactive architecture diagram in 1–2 seconds.

- Built a **custom DSL language** (DiagramDSL) from scratch — lexer, recursive-descent parser, resolver
- **Gemini AI** converts NLP → DiagramDSL → **ELK** layout → **D3.js** SVG render
- Live bidirectional selection, syntax highlighting, drag-to-edit, dark/light mode, PNG/SVG export
- **FastAPI** backend with 9 endpoints | **React** (Vite) frontend

`Python` `FastAPI` `React` `D3.js` `ELK` `Gemini AI` `Custom DSL`

---

### 🤖 PrepAI
> *AI-powered interview prep for candidates + automated screening for companies*

A dual-sided platform with a 3-tier context system — the more context you give, the more personalised the output.

- **Web scraping** pipeline: GFG interview experiences + Reddit (PRAW API) → **RAG pipeline** (LangChain + Pinecone/ChromaDB)
- **Agentic AI interview** with tool-calling loop, Whisper STT, ElevenLabs TTS, HeyGen avatar
- **ATS scoring engine**: resume scoring, semantic keyword matching, CV rebuild + cover letter generation
- **LLM orchestration**: Claude/GPT-4o with structured output and schema enforcement

`Python` `FastAPI` `React` `LangChain` `Pinecone` `ChromaDB` `Whisper` `Claude API` `RAG`
